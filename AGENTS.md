## Mission

Build and maintain the customer-facing Project MISE landing page hosted at
chefcory.com.

Project MISE is a restaurant operating-intelligence platform intended to help
independent restaurants access practical financial, culinary, procurement,
operational, and business decision support.

## Current Scope

The current project is a static landing page only.

Do not add:

- Databases
- Authentication
- Customer portals
- Agent infrastructure
- Azure backend services
- Payment processing
- APIs

unless Cory explicitly authorizes the change.

## Git Workflow

1. Pull the latest main branch.
2. Do not work directly on main.
3. Create a branch using:

   forge/feature-description
   forge/fix-description
   forge/content-description

4. Test the landing page locally.
5. Commit with a clear message.
6. Push the branch to GitHub.
7. Create a pull request for Cory.
8. Do not merge without explicit authorization.

## Security

Never commit passwords, tokens, credentials, connection strings, customer
records, private financial information, or proprietary restaurant data.

## Brand Direction

Project MISE should communicate:

- Restaurant operating intelligence
- Chef-informed technology
- Practical financial clarity
- Food-cost and plate-cost visibility
- Support for independent operators
- Enterprise-level capability made accessible
- Purpose before hype
- Clear, actionable business decisions

Avoid implying that Project MISE replaces licensed accountants, attorneys,
tax professionals, or other regulated professionals.
